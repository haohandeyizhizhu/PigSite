## v0.2 — 全站换为卡通小猪风格（个人卡通形象）

用户要求把小猪作为其**个人卡通形象**，整站视觉随之重做。仍是单文件、零依赖。

### 小猪形象实现方式（关键决策：用 SVG `<symbol>` 而不是位图）
- `<defs>` 中定义两个 symbol：`#pig-head`（头，viewBox 0 0 120 120）与 `#pig-full`（全身，viewBox 0 0 164 176，内部用 `<use href="#pig-head" transform="translate(30 -3) scale(.85)">` 嵌套复用头部）。
- **好处**：改一处全站所有小猪同步更新；无限缩放不糊；可染色、可加动作；不用 GIF。
- 全站 6 处引用同一个头部 symbol（logo / 首屏 / 3 张卡片 / 页脚 / section 小标）。
- 图标（favicon）用内联 SVG data URI，`#` 需写成 `%23`。

### 动画（纯 CSS，定义在 symbol 内部，`<use>` 实例自动继承）
- 眨眼 `.pig-eyes`：`transform-box: fill-box; transform-origin: center` + `scaleY(.10)`，周期 4.8s。**注意：SVG 里做缩放动画必须加 `transform-box: fill-box`，否则 iOS/部分内核会绕 SVG 原点缩放。**
- 摇尾巴 `.pig-tail`：`transform-box: fill-box` 绕自身中心 rotate ±9°，2.4s alternate。
- 浮动 `.pig-float`、装饰星/心闪烁 `twinkle`、hover 抖动 `wiggle`。
- 各实例用 `style="--d:0.8s"` 传自定义属性错开眨眼时机（自定义属性可穿透 use 影子树）。
- 已加 `prefers-reduced-motion: reduce` 兜底。

### 视觉规则（卡通 / 贴纸风）
- 硬边界 + 硬投影：卡片 `border: 3px solid var(--line)` + `box-shadow: 0 7px 0 0 var(--line-soft)`（0 模糊度的"贴纸"阴影），hover 上浮并轻微旋转。
- 按钮做 3D 按压：投影 `0 5px 0 0 var(--brand-deep)`，`:active` 时 `translateY(5px)` 且投影归零。
- 配色：主色樱花粉 `#F0698F`，描边 `#D9567A`，皮肤 `#FBC2D5`；**文字用暖棕紫 `#45333C` 而非冷灰**（卡通感的关键之一）；点缀薄荷 `#7ED9C0` / 奶油黄 `#FFD06B` / 天蓝 `#93C9FF`。
- 背景：`body::before` 铺 26px 间距的淡粉波点，底部用 mask 渐隐。
- 圆角加大：卡片 28px、导航胶囊 999px。

### 内容变化
- 首屏改为形象自我介绍 + 对话气泡；"示例数据表"改为**角色设定表**（名字/性格/口头禅/招牌动作/主色）；新增**配色卡**区块（6 个 swatch 直读 CSS 变量）。

## v0.3 已落地 —— 「一屏养小猪」交互小游戏

用户授权「三个问题你自己决定」，于是按以下决定实现：节奏取演示友好档（饱食度 60 起步、0.8/秒衰减，约 2 分钟饿一轮）；画风从「糖果贴纸」退到**克制的现代扁平**（去掉粗描边、0 模糊度硬投影、波点背景；文字用暖棕紫 `#3A3238`；小猪改细描边 2.5、灰玫瑰 `#E8AEB8`/`#D98D9E`/`#B97A8B`；加入 localStorage + 挂机补算）。

### 文件
仍只有 `D:\Document\code\PigSite\index.html`（25.8KB，零依赖，单文件）。整页 100dvh 不滚动，分三块：顶部状态 / 中间舞台 / 底部三个按钮。

### 小猪形象
单个 `<svg viewBox="0 0 200 214">`，靠 `data-face` + `data-mouth` 两个属性切表情，CSS 用 `.pig[data-face="x"] .eyes--x { display:block }` 控制显隐（默认 `.eyes`/`.mouth` 全部 `display:none`；**眨眼规则的优先级要写在表情规则之后**才能覆盖）。
- 4 组眼（open / happy 眯眼笑 / sad 含耷拉眉毛+泪珠 / sleep）、1 组眨眼、4 个嘴。
- 耳朵/尾巴的旋转**不能用 CSS transform**（会绕 SVG 原点转飞）。做法：JS 每帧 `setAttribute('transform', 'rotate(deg cx cy)')`，显式指定旋转中心。
- 胖瘦用 CSS `transform: scaleX()` 作用在 **HTML 元素 `.pig-wrap`** 上（不是 SVG 内部），origin `50% 100%` 保证脚不离地；三层嵌套各管一种 transform 避免互相覆盖：`.pig-wrap`(胖瘦) → `.pig__bob`(呼吸) → `svg`(咀嚼)。
- 掉落食物用**两层嵌套 div 分别跑 translateX 线性 / translateY 缓入**，合成抛物线，纯 CSS 无 JS 逐帧。

### 数值设计
饱食度 60 起、0.8/s 衰减（睡 0.32/s）；心情 >60 饱食度时 +0.12/s、<30 时 −0.4/s；喂食 +22 饱食度/+3 心情/+0.25kg，冷却 1.2s；≥95 再喂 → 心情 −6 打嗝；摸摸 +4 心情冷却 2s；体重 >40 触发减肥台词。表情阈值：sad(饱食度<30 或 心情<30) / happy(心情>60 且 饱食度>45) / open。

### 踩到的三个真 bug（都靠自动化验证抓出来，肉眼很难发现）
1. **时间基准混用**：`render(now)` 里的 `now` 是 `requestAnimationFrame` 的**相对**时间戳，却拿去和 `Date.now()` 的**绝对**时间相减 → 页头显示「第 **-20718** 天」；同时 `now < chewing` 恒为真 → 首次喂食后嘴巴永远抽搐。修法：逻辑一律用 `Date.now()`，`performance.now()` **只**用于动画相位（`Math.sin(wall/260)` 对 1.8e12 这种大数会丢精度，必须用单调时间）。
2. **rAF 在标签页不可见时被浏览器暂停** → 切走再切回，小猪一口都不饿。修法：主循环改为**挂钟驱动**（`dt = Date.now() - lastWall`，双保险再加 `setInterval(frame, 1000)` 心跳；因为 dt 由挂钟推导，重复调用不会重复计数），并在 `visibilitychange` 变可见时用 `simulate(gap)` 补算。
3. 撑到时不加冷却 → 可瞬间把心情刷到 0。

### 可复用方法：看不见图片时如何验证前端
本模型读不了图片，`agent-browser` 也没装，改用 **headless Chrome + 注入探针**：
1. 探针用 `@@JSON@@` 包裹写入 `<pre>`（**不要用 `<@>`**，`<` 在 textContent 里会被序列化成 `&lt;` 导致抓不到）；
2. `chrome --headless=new --virtual-time-budget=6000 --dump-dom` 把 DOM 打到 stdout，正则抠出 JSON；
3. 用 `getBBox()` 校验手画 SVG 的几何关系（耳朵高于头顶、鼻子在头内、腿伸出身体、左右对称等）；用 `getBoundingClientRect()` 校验溢出/裁切；用 `ComputedStyle().display` 校验到底哪组表情可见。
4. **坑**：PowerShell 抓子进程 stdout 会按 GBK 解码，中文必然乱码 —— 判断编码别信这个，要 `ReadAllBytes` 看原始字节（`E5 85 BB` = 养）；要看中文字符是否正确，就传 `charCodeAt` 数组出来比。
5. **坑**：`getBBox()` 对 `display:none` 子树返回 0，测隐藏元素前先临时把 `data-face` 切到显示它的那一档。
6. 探针要插在 `<body>` 之后、页面脚本之前，才能捕获页面脚本的 `window.onerror`。

## v0.4 — 修「喂食键不可见」

用户反馈：喂食键鼠标不移上去就看不见。**在干净浏览器里无法复现** —— 探针实测：底色 `rgb(217,141,158)`、白字、1px 同色描边、`opacity:1`、`elementFromPoint(按钮中心)` 就是按钮自己（无遮挡）、`stage` 不与 actions 重叠、四种视口（764/604/504/424px 高）下 `appOverflow:0` 且按钮完整在视口内。

因此判定为**宿主环境的外部样式覆盖**，依据是症状本身：`.btn--feed` (0,1,0) 被盖、`:hover` (0,3,0) 生效 → 存在特异度介于两者之间的外来规则。

修法（已写进 MEMORY.md 的「交互元素必须抗改写」章节）：改用 `#id` 选择器 + `background/color/border-color/opacity` 加 `!important`（不碰 `width`，那是 JS 写的）+ 颜色带 `var(--x, 兜底)` + `:root` 加 `color-scheme: light`。
**回归测试**：注入两级敌意样式（高特异性普通规则、以及带 `!important` 的规则）后，按钮底色算出来完全不变；截图做像素比对，粉色像素 7291 → 7292，等于没变。

顺带修掉两个真 bug：
- `.actions .btn--feed { flex: 1.5 }` 被写在 `.actions .btn { flex: 1 }` 之前，同特异度后者胜 → 主按钮没变宽。现喂食键 166px、另两个 117px。
- `#satietyBar` / `#moodBar` 的填充底色同样脆弱（被抹掉就等于「进度条是空的」，会误导读数），一起加固。

### 新增的可复用手段
- **纯 Python 解 PNG 看渲染结果**（不装任何库：自己解析 IHDR/IDAT + zlib.decompress + 手工反滤波），把图降采样成 56 列字符画。模型看不见图片时，这是唯一能"看到"布局的办法 —— 本次正是靠它确认了耳朵是头顶两个独立块、深粉鼻子在脸中央、尾巴从右侧探出、两条腿在身体下方。
